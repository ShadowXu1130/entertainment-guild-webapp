# Entertainment Guild Web App

This project is a full-stack web application prototype for Entertainment Guild.

## Planned Features
- User login and registration
- Product browsing and search
- Shopping cart and order placement
- Admin inventory management
- Backend API and database integration

## Sprint Plan
Week 3: Project setup, GitHub repository, React frontend setup.
Week 4: Authentication and user interface development.
Week 5: Product browsing and search features.
Week 6: Cart, orders, and database integration.
Week 7: Admin dashboard and inventory management.
Week 8: Testing, bug fixing, and UI refinement.

## Team Workflow
The team will use GitHub commits, sprint planning, and regular SCRUM updates to track progress.
